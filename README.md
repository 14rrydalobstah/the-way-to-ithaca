# 归航 · The Way to Ithaca

奥德修斯背景的单机骰子回合制 Roguelike 原型。带领三人队伍选择海陆航线，获得随机招式、装备和神赐，挑战第九层首领归乡。

当前试玩版本：**0.5.2**。采用几何占位画面，玩法与平衡仍在调整。

## 下载就能玩

1. 打开本仓库右侧 **Releases**，选择最新版本，下载 **Ithaca-Playtest-v0.5.2.zip**。不要只下载单个 HTML 文件。
2. 将 ZIP **完整解压**到一个文件夹。
3. 双击 **开始游戏.html**（或 `index.html`），用 Chrome / Edge 打开。

无需联网、账号、安装程序、Node.js 或 Python。所有脚本和样式需保留在同一个文件夹。直接在 ZIP 内预览文件可能无法正常运行。

手机体验暂未验证，推荐电脑浏览器。

## 怎么玩

- 输入旅程种子，点击“新旅程”。不同种子产生不同旅程。
- 从相连航路中选择下一站，比较天数、口粮、睡眠条件和环境迹象。
- 点击左侧角色选择行动者。普通回合每人 3 行动，突袭阶段 2 行动；普通攻击、瞄准和防御通常各需 2 行动。
- 战场上方显示敌人下一步动作及攻击对象。部分敌人可以突进后攻击；弓箭贴身仍能使用，但有命中劣势。
- 战利品可能放入团队背包。秘籍和神赐需选择角色分配，团队经营物品自动生效。
- 海上睡眠与陆地休息恢复内容不同，城邦可补给和住宿。倒地者需战后复苏药救治。
- 顶部“航线地图”随时查看历史与前方航路。

完整数值见 [完整规则](完整规则.md)。

## 保存和反馈

保存需要点击顶部“保存”，下次在同一浏览器、同一入口点“读取”。更换文件夹或浏览器可能影响存档识别；清理浏览器数据会删除存档。

顶部“导出记录”可以保存本局操作与骰面。浏览器支持时可选择导出目录，否则使用普通下载。反馈时请附上记录文件，重点说明：

1. 哪个掉落改变了打法？
2. 资源是否影响了路线选择？
3. 是否想换个种子再玩？哪里单调、卡住或看不懂？

记录可能包含你输入的旅程种子和游戏内操作；发送前可以自行查看。游戏没有内置远程上传或数据收集。

## 开发检查

仅修改源码或运行内部检查时需要 Node.js。运行 `node tests/combat-batch-tests.cjs`、`node tests/expedition-tests.cjs`、`node tests/expansion-tests.cjs` 和 `node tests/probability-route-tests.cjs`。

本仓库不包含开发者的个人试玩记录或浏览器存档。
